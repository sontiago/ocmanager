# Фикстуры `occtl -j`

Сняты с живого ocserv из `ocserv/Dockerfile` (версия — в `VERSION.txt`) при
подключённых клиентах `c9001-d1`, `c9001-d2` из dev-стенда. При обновлении
ocserv фикстуры переснимаются (Задача 1.3, шаг 1), и `test_parser.py`
показывает, что поменялось.

| Файл               | Команда                | Состояние                          |
| ------------------ | ---------------------- | ---------------------------------- |
| `users_two.json`   | `occtl -j show users`  | подключены `c9001-d1` и `c9001-d2` |
| `users_one.json`   | `occtl -j show users`  | подключён `c9001-d1`               |
| `users_empty.json` | `occtl -j show users`  | никого                             |
| `status.json`      | `occtl -j show status` | один клиент                        |

Ключи, на которые опирается парсер:

| Ключ                       | Тип в JSON                     | Смысл                                          |
| -------------------------- | ------------------------------ | ---------------------------------------------- |
| `ID`                       | число                          | id сессии; `$ID` в хуках — то же значение      |
| `Username`                 | строка                         | CN сертификата                                 |
| `Remote IP`                | строка                         | IP клиента                                     |
| `IPv4`                     | строка                         | адрес клиента в VPN                            |
| `RX` / `TX`                | **строка с числом** (`"3180"`) | байты от клиента / к клиенту                   |
| `_RX` / `_TX`              | строка                         | то же для людей (`"3.1 KB"`) — не использовать |
| `raw_connected_at`         | число                          | unix-время подключения                         |
| `User-Agent`               | строка                         | клиент                                         |
| `Status` (status)          | строка                         | `"online"`                                     |
| `Active sessions` (status) | число                          |                                                |
| `uptime` (status)          | число                          | секунды                                        |

Особенности ocserv 1.3.0: в `show users` ключ `Routes` встречается дважды
(массив и строка) — `json.loads` оставляет последний, парсеру он не нужен;
`occtl -j show sessions all` выдаёт невалидный JSON (висячая запятая) —
не используем.
