## Отложено решением владельца

### Оплата другими способами (Telegram Stars, криптоплатежи) — этап 2, проект 4

Сейчас оплата только через Tribute. Перед стартом нужно решить (вопросы заданы 2026-10-23, ответов нет):

1. Что покупают: разовый период без автопродления (рекомендация — так, плюс напоминание за N дней, оно уже есть)
   или подписку с автопродлением (у Stars рекуррентность только для каналов).
2. Где платят Stars: в чате с ботом через `sendInvoice` (валюта `XTR`, `pre_checkout_query`,
   `successful_payment`) — рекомендация; либо из Mini App через `openInvoice` (правки в TMA).
3. Крипто-провайдер: CryptoBot (Crypto Pay, HMAC-вебхук) — рекомендация; NOWPayments/Cryptomus; свой кошелёк.
4. Цены: ручные цены по провайдерам в тарифе (рекомендация) или пересчёт из рублёвой по курсу.
5. Возвраты: возврат Stars из админки (`refundStarPayment`), для крипты только статусы и ручной разбор.
6. Уведомления: хватает ли текущих («оплата получена», «скоро закончится»).

Что уже есть в коде: контракт `billing/providers/base.py` (`PaymentProvider`: `verify`, `event_id`, `parse`),
`ProviderEvent` с `amount`/`currency`/`period_end`, связь тарифа с продуктом через `provider_product_ids`,
идемпотентность `payments UNIQUE(provider, external_id)`, повторная обработка вебхуков из админки.

### Мультинодовость — этап 4 спеки

`RemoteAgentDriver`, агент на ноде, выбор локации в TMA, health-чеки и переключение, распределение клиентов
по нодам. Отдельная спека и план, когда понадобится.

## Хвосты проекта «веб-админка» (из финального ревью, Minor)

- Поле поиска в «Клиентах» и «Устройствах» не синхронизируется с URL при «Назад» и клике по пункту меню.
- Логи: 503 до старта потока показывается как «соединение потеряно»; 401 на потоке не ведёт на логин.
- Фильтр «онлайн» в «Устройствах» при пустом кэше здоровья показывает общую ошибку (503 от бэкенда).
- Несуществующий `/assets/*` отдаёт `index.html` со статусом 200; у `index.html` нет `Cache-Control: no-cache`.
- Диалоги без фокус-ловушки и возврата фокуса; кликабельные строки таблиц недоступны с клавиатуры.
- Форма «Настройки» сравнивается с обновлённым снимком; пустое числовое поле шлёт 0/NaN.
- Обзор показывает сырые ключи статусов подписок; английские сообщения бэкенда в русском интерфейсе.
- Нет блока «Динамика» на Обзоре; сохранённый `last_reconcile_report` не показан на странице ноды.
- Кнопка подтверждения TOTP не блокируется на время запроса.
- `frontend/admin/.dockerignore` для именованного контекста сборки не проверен на Docker с macOS `node_modules`.
- `npm run api:check` существует, но не подключён к CI (нужна выгрузка OpenAPI без живого `api-admin`).

## Идеи без решения

- Затраты на сервер и прибыль в статистике (нужна настройка «стоимость сервера в месяц»).
- Проверка квоты чаще, чем раз в 5 минут (сейчас клиент может превысить лимит на трафик за интервал опроса).
