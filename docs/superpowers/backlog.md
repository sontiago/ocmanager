### Оплата другими способами (Telegram Stars, криптоплатежи) — этап 2, проект 4

Сейчас оплата только через Tribute. Перед стартом нужно решить (вопросы заданы 2026-10-23, ответов нет):

1. Что покупают: разовый период без автопродления (рекомендация — так, плюс напоминание за N дней, оно уже есть)
   или подписку с автопродлением (у Stars рекуррентность только для каналов).
2. Где платят Stars: в чате с ботом через `sendInvoice` (валюта `XTR`, `pre_checkout_query`,
   `successful_payment`) — рекомендация; либо из Mini App через `openInvoice` (правки в TMA).
3. Крипто-провайдер: CryptoBot (Crypto Pay, HMAC-вебхук) — рекомендация; NOWPayments/Cryptomus; свой кошелёк.
4. Цены: ручные цены по провайдерам в тарифе (рекомендация) или пересчёт из рублёвой по курсу.
5. Возвраты: возврат Stars из админки (`refundStarPayment`), для крипты только статусы и ручной разбор.
6. Уведомления: хватает ли текущих («оплата получена», «скоро закончится»).

Что уже есть в коде: контракт `billing/providers/base.py` (`PaymentProvider`: `verify`, `event_id`, `parse`),
`ProviderEvent` с `amount`/`currency`/`period_end`, связь тарифа с продуктом через `provider_product_ids`,
идемпотентность `payments UNIQUE(provider, external_id)`, повторная обработка вебхуков из админки.

## Решения, принятые осознанно (не хвосты)

- Возврат платежа награду за приглашение не отзывает; в админке такая награда помечена «платёж возвращён», решает
  админ вручную.
- Промокод применим только к клиенту с подпиской (живой, исчерпанной или истёкшей).
- Использованный промокод не удаляется, только выключается: на него ссылаются журнал погашений и аудит.

## Ручная проверка с живым Telegram (автоматически не покрыта)

1. В `.env` боевого или тестового стенда задан `OCM_BOT_USERNAME`.
2. Клиент A открывает Mini App → «Аккаунт» → «Друзья и бонусы»: виден код и ссылка, «Поделиться» открывает окно
   отправки Telegram.
3. Клиент B (новый аккаунт) переходит по ссылке `t.me/<бот>?start=ref_<код>`, нажимает Start; в админке в карточке B
   «Пригласил» = A. Повтор с другим кодом B не перепривязывает.
4. B оплачивает тариф через Tribute: после вебхука B получает +3 дня, A получает +7 дней; обоим пришло сообщение
   в Telegram; в админке «Рефералы» появилась награда.
5. Ссылка Mini App `?startapp=ref_<код>` у нового клиента привязывает так же, как `/start`.
6. «Аккаунт» → «Промокод»: правильный код применяется, повтор — «уже использовали», выдуманный — «недействителен».
