# Глоссарий

| Термин | Значение |
|---|---|
| **ocserv** | OpenConnect VPN-сервер; клиенты: Cisco AnyConnect, OpenConnect |
| **нода** | экземпляр ocserv, которым управляет панель (сейчас одна, на том же сервере) |
| **NodeDriver** | интерфейс управления нодой; реализация сейчас одна, `LocalDockerDriver` |
| **CA** | собственный удостоверяющий центр; ключ `ca.key` есть только у панели, у ноды `ca.crt` |
| **CRL** | список отозванных сертификатов; ocserv применяет его к новым подключениям |
| **`.p12`** | файл ключа устройства (сертификат + приватный ключ), защищён паролем, выдаётся один раз |
| **устройство** | один ключ клиента; логин на ноде `c<id клиента>-d<номер>`; один ключ — одна сессия |
| **`allowed.list`** | файл с логинами, которым можно подключаться; выводится из БД |
| **камуфляж** | секрет в URL шлюза: без него сервер выглядит как обычный сайт |
| **reconcile (сверка)** | задача раз в 5 минут: приводит ноду к состоянию БД и пишет «дрейфы» в аудит |
| **дрейф** | расхождение ноды и БД, найденное сверкой |
| **outbox** | таблица, куда события/сообщения пишутся в одной транзакции с изменением; доставка отдельно |
| **domain event** | событие вида `subscription.activated`; доставляется at-least-once |
| **flows** | слой склейки доменных модулей: единственное место, где модули «знают» друг друга |
| **initData** | подписанная Telegram строка с данными пользователя Mini App; основа авторизации клиента |
| **TMA** | Telegram Mini App, клиентское приложение |
| **Tribute** | платёжный провайдер (Telegram), присылает вебхуки |
| **runtime-настройки** | параметры, которые владелец меняет из админки без перезапуска (хранятся в таблице `settings`) |
| **квота / exhausted** | лимит трафика подписки исчерпан: статус `exhausted`, доступ закрыт |
| **дрейф-аудит** | записи `reconcile.*` в `audit_log` |
| **`ocm`** | команда обслуживания установки (`status`, `update`, `backup` …) |
